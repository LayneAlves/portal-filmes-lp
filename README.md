# 🎨 Landing Page - Streaming UI

## 📖 Sobre o projeto

Este projeto consiste em uma landing page inspirada em plataformas de streaming, desenvolvida com o objetivo de demonstrar minhas habilidades em design de interfaces, experiência do usuário (UI/UX) e desenvolvimento front-end.

O foco do projeto está na criação de uma interface moderna, organizada e visualmente atrativa, aplicando boas práticas de HTML, CSS e JavaScript.

## ✨ Objetivos

- Demonstrar habilidades em UI/UX;
- Desenvolver uma interface moderna e intuitiva;
- Aplicar boas práticas de HTML, CSS e JavaScript;
- Criar uma experiência visual agradável e responsiva.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
